## 一、文件目录操作命令

### 1. ls – 显示目录内容列表

**含义：** 显示目录内容列表

**语法：** `ls [选项] (文件名)`

**常用选项：**

| 选项 | 描述                 |
| ---- | -------------------- |
| -l   | 显示详细信息         |
| -a   | 显示所有包含隐藏文件 |

**示例：**

```bash
# 基础用法
[root@linux141 ~]# ls
anaconda-ks.cfg

# 显示详细信息
[root@linux141 ~]# ls -l
total 4
-rw-------. 1 root root 1493 Feb 23 22:20 anaconda-ks.cfg

# 显示隐藏文件
[root@linux141 ~]# ls -a
.  ..  anaconda-ks.cfg  .bash_history  .bash_logout  .bash_profile  .bashrc  .cshrc  .tcshrc  .viminfo

# 显示指定目录下的内容
[root@linux141 ~]# ls /etc/
abrt                     ethertypes   ld.so.conf                polkit-1        sos.conf
adjtime                  exports      ld.so.conf.d              popt.d          ssh
```

### 2. cd – 切换用户当前工作目录

**含义：** 切换用户当前工作目录

**语法：** `cd [选项] [目录]`

**常用形式：**

| 形式      | 描述             |
| --------- | ---------------- |
| cd 或 cd~ | 回到家目录       |
| cd ..     | 回到上级目录     |
| cd .      | 进入当前目录     |
| cd -      | 返回上次所在目录 |

**示例：**

```bash
# 切换工作目录
[root@linux141 ~]# pwd
/root
[root@linux141 ~]# cd /etc/
[root@linux141 etc]# pwd
/etc

# 回到家目录（两种方式）
[root@linux141 etc]# cd
[root@linux141 etc]# cd ~

# 返回上级目录
[root@linux141 network-scripts]# cd ../..
[root@linux141 etc]# pwd
/etc

# 返回上次所在目录
[root@linux141 etc]# cd -
/etc/sysconfig/network-scripts
```

### 3. pwd – 显示当前所在目录

**含义：** 显示当前所在目录

**语法：** `pwd`

**示例：**

```bash
[root@linux141 network-scripts]# pwd
/etc/sysconfig/network-scripts
```

### 5. mkdir – 创建目录

**含义：** 创建目录

**语法：** `mkdir [选项] (文件名)`

**常用选项：**

| 选项 | 描述         |
| ---- | ------------ |
| -p   | 创建多级目录 |

**示例：**

```bash
# 基础用法
[root@linux141 ~]# mkdir /app
[root@linux141 ~]# ls -d /app/

[root@linux141 ~]# mkdir -p /app/tools/after/20230402
[root@linux141 ~]# tree /app/

        └── 20230402
```

### 7. cp – 复制文件或目录

**含义：** 复制文件或目录

**语法：** `cp [选项] (源文件) (目标文件)`

**常用选项：**

| 选项 | 描述                                 |
| ---- | ------------------------------------ |
| -r   | 递归复制                             |
| -p   | 复制的时候属性不变                   |
| -d   | 复制的时候复制软连接                 |
| -a   | -a相当于-p -d -r                     |
| -b   | 覆盖已存在的文件目标前将目标文件备份 |

**示例：**

```bash
# 复制文件
[root@linux141 ~]# cp /etc/hostname /app/
[root@linux141 ~]# tree /app/
/app/
├── hostname
└── tools
    └── after
        └── 20230402
            ├── 1
            ├── 2
            ├── 3
            ├── 4
            └── 5

3 directories, 6 files

# 递归复制（复制目录）
[root@linux141 ~]# cp -a /etc/sysconfig/ /app/
[root@linux141 ~]# tree /app/
/app/
├── hostname
├── sysconfig
│   ├── anaconda
│   ├── authconfig
│   ├── cbq
│   │   ├── avpkt
│   │   └── cbq-0000.example
│   ├── chronyd
│   ├── console
...

# 覆盖前备份
[root@linux141 ~]# cp -ab /etc/hostname /app/
cp: overwrite ‘/app/hostname’? y
[root@linux141 ~]# ll /app/
total 12
-rw-r--r--  1 root root    9 Apr  5 15:23 hostname
-rw-r--r--  1 root root    9 Apr  5 15:54 hostname~
drwxr-xr-x. 6 root root 4096 Feb 23 22:33 sysconfig
drwxr-xr-x  3 root root   19 Apr  5 15:47 tools
```

### 8. mv – 移动文件或目录，重命名

**含义：** 移动文件或目录，重命名

**语法：** `mv [选项] (源文件) (目标文件)`

**示例：**

```bash
# 移动文件
[root@linux141 ~]# mv /app/hostname /app/tools/
[root@linux141 ~]# ls /app/
hostname~  sysconfig  tools
[root@linux141 ~]# ls /app/tools/
after  hostname

# 重命名
[root@linux141 ~]# mv /app/hostname~ /app/hostname
[root@linux141 ~]# ls /app/
hostname  sysconfig  tools
```

### 9. rm – 删除文件或目录

**含义：** 删除文件或目录

**语法：** `rm [选项] [文件]`

**常用选项：**

| 选项 | 描述           |
| ---- | -------------- |
| -f   | 强制删除不提示 |
| -r   | 递归删除目录   |

**示例：**

```bash
# 普通删除
[root@linux141 ~]# rm /app/tools/hostname
rm: remove regular file ‘/app/tools/hostname’? y
[root@linux141 ~]# ls /app/tools/
after

# 强制删除
[root@linux141 ~]# rm -f /app/hostname
[root@linux141 ~]# ls /app/
sysconfig  tools

# 递归删除目录
[root@linux141 ~]# rm -rf /app/sysconfig/
[root@linux141 ~]# ls /app/
tools
```

### 10. ln – 为文件创建链接

**含义：** 用来为文件创建链接

**语法：** `ln [选项] (源文件) (链接名)`

**常用选项：**

| 选项 | 描述                                   |
| ---- | -------------------------------------- |
| -s   | 创建软连接                             |
| -d   | 创建指向目录的硬链接(只适用于超级用户) |

**示例：**

```bash
# 默认格式：创建硬链接
[root@linux141 ~]# ln grep.txt grep.txt.local
[root@linux141 ~]# ll grep*
-rw-r--r-- 2 root root 104 Apr  6 21:27 grep.txt
-rw-r--r-- 2 root root 104 Apr  6 21:27 grep.txt.local

# 创建软连接
[root@linux141 ~]# ln -s grep1.txt grep.txt.scft
[root@linux141 ~]# ll grep*
-rw-r--r-- 1 root root  38 Apr  6 21:31 grep1.txt
lrwxrwxrwx 1 root root   9 Apr  6 21:43 grep.txt.scft -> grep1.txt
```

### 11. find – 查找文件

**含义：** 查找文件

**语法：** `find (大体位置) [选项] (文件)`

**常用选项：**

| 选项   | 描述                                                         |
| ------ | ------------------------------------------------------------ |
| -type  | 查找什么类型文件 f (file 文件) d(directory 目录) l(softlink 软连接） |
| -name  | 指定文件名                                                   |
| -size  | 指定文件大小+10k(k G M)                                      |
| -mtime | 指定文件修改时间+7 7天之前                                   |
| -iname | 指定文件名，不区分大小写                                     |

**示例：**

```bash
# 基础格式
[root@linux141 ~]# find /etc/ -name 'hostname'
/etc/selinux/targeted/active/modules/100/hostname
/etc/hostname

# 指定文件类型
[root@linux141 ~]# find /etc/ -type f -name 'hostname'
/etc/hostname

# 配合正则使用
[root@linux141 ~]# find /etc/ -type f -name '*.conf'
/etc/resolv.conf
/etc/pki/ca-trust/ca-legacy.conf

# 指定文件大小（/etc下面大于50kb小于100kb文件）
[root@linux141 ~]# find /etc/ -type f -size +50k -size -100k
/etc/pki/nssdb/cert8.db
/etc/openldap/certs/cert8.db
/etc/selinux/targeted/active/modules/100/base/cil
/etc/selinux/targeted/active/modules/100/base/hll
/etc/lvm/lvm.conf
/etc/bash_completion.d/git
/etc/vmware-tools/vgauth/schemas/XMLSchema.xsd

# 指定时间（/etc下面大于50kb且7天之前的文件）
[root@linux141 ~]# find /etc/ -type f -size +50k -mtime +7
/etc/pki/ca-trust/extracted/java/cacerts
/etc/pki/ca-trust/extracted/openssl/ca-bundle.trust.crt
...
```

### 12. xargs – 参数转换

**含义：** 与管道类似，传递的内容会被xargs转换，文字符号→参数，一般与find使用

**示例：**

```bash
[root@linux141 ~]# find /etc/sysconfig/ -type f -name "*.conf" | xargs ls -l
-rw-r--r--. 1 root root 211 Aug  9  2019 /etc/sysconfig/trace-cmd.conf
```

### 13. chattr – 改变文件属性

**含义：** 改变文件的扩展属性（如不可修改）

**语法：** `chattr [选项] [模式] 文件`

**常用选项：** `+i`（设置不可修改），`-i`（取消不可修改），`+a`（只允许追加）

**示例：**

```bash
[root@linux141 ~]# chattr +i /etc/resolv.conf
[root@linux141 ~]# rm /etc/resolv.conf
rm: cannot remove ‘/etc/resolv.conf’: Operation not permitted
[root@linux141 ~]# chattr -i /etc/resolv.conf
```

### 14. lsattr – 查看文件扩展属性

**含义：** 查看文件的扩展属性

**语法：** `lsattr [选项] 文件`

**示例：**

```bash
[root@linux141 ~]# lsattr /etc/resolv.conf
----i----------- /etc/resolv.conf
```

**含义：** 探测文件类型

**语法：** `file [选项] 文件`

**示例：**

### 16. chown – 修改文件所有者

**含义：** 修改文件或目录的所有者和所属组

**语法：** `chown [选项] [用户][:组] 文件`

**示例：**

```bash
[root@linux141 ~]# chown linux:linux /app/test.txt
[root@linux141 ~]# ll /app/test.txt
-rw-r--r-- 1 linux linux 0 Apr  8 10:00 /app/test.txt
```

### 17. chmod – 修改文件权限

**含义：** 修改文件或目录的权限

**语法：** `chmod [选项] 模式 文件`

**权限模式：** 数字法（如 755）或符号法（如 u+x）

**示例：**

```bash
[root@linux141 ~]# chmod 755 /app/script.sh
[root@linux141 ~]# chmod u+x /app/script.sh
[root@linux141 ~]# chmod -R 755 /app/dir/
```

## 二、文件过滤及内容编辑命令

### 1. cat – 显示文件内容

**含义：** 显示，查看文件内容

**语法：** `cat [选项] (文件)`

**常用选项：**

| 选项 | 描述                   |
| ---- | ---------------------- |
| -n   | 显示文件内容并加上行号 |

**示例：**

```bash
# 基础格式
[root@linux141 ~]# cat /etc/sysconfig/network-scripts/ifcfg-eth1
TYPE=Ethernet
PROXY_METHOD=none
BROWSER_ONLY=no
BOOTPROTO=none
...

# 显示行号
[root@linux141 ~]# cat -n /etc/sysconfig/network-scripts/ifcfg-eth1
     1  TYPE=Ethernet
     2  PROXY_METHOD=none
     3  BROWSER_ONLY=no
     4  BOOTPROTO=none
...
```

### 2. more – 分页查看文件内容

**含义：** 按页查看文件内容，查看到文件结尾自动退出

**语法：** `more [选项] (文件)`

**内部快捷键：**

| 按键         | 功能                   |
| ------------ | ---------------------- |
| 空格或Ctrl+f | 向下一页               |
| b 或 Ctrl+b  | 向上一页               |
| G            | 快速定位到文件最后一行 |
| g            | 快速定位到文件第一行   |
| /字符串      | 向下搜索               |
| n            | 继续向下搜索           |
| N            | 继续向上搜索           |
| q            | 退出                   |

**示例：**

```bash
[root@linux141 ~]# more /var/log/messages
```

### 3. less – 分页查看文件内容（可回翻）

**含义：** 按页查看文件内容，查看到文件结尾还可以继续查看

**语法：** `less [选项] (文件)`

**内部快捷键：** 同 more，且支持上下箭头逐行滚动

**示例：**

```bash
[root@linux141 ~]# less /var/log/messages
```

### 4. head – 显示文件开头部分

**含义：** 显示文件开头部分，默认显示10行

**语法：** `head [选项] (文件)`

**常用选项：**

| 选项 | 描述       |
| ---- | ---------- |
| -n   | 显示多少行 |

**示例：**

```bash
# 默认10行
[root@linux141 ~]# head /etc/services

# 显示前15行（两种方式）
[root@linux141 ~]# head -n 15 /etc/services
[root@linux141 ~]# head -15 /etc/services
```

### 5. tail – 显示文件结尾部分

**含义：** 显示文件最后行数，默认显示10行

**语法：** `tail [选项] (文件)`

**常用选项：**

| 选项 | 描述               |
| ---- | ------------------ |
| -n   | 显示指定行数       |
| -f   | 显示文件的跟踪输出 |

**示例：**

```bash
# 默认10行
[root@linux141 ~]# tail /etc/services

# 显示最后15行
[root@linux141 ~]# tail -n 15 /etc/services
[root@linux141 ~]# tail -15 /etc/services

# 实时跟踪日志
[root@linux141 ~]# tail -f /var/log/messages
```

### 6. tailf – 跟踪日志输出（等同于 tail -f）

**含义：** 通常用于日志文件的跟踪输出，与`tail -f`一致

**示例：**

```bash
[root@linux141 ~]# tailf /var/log/messages
```

### 7. wc – 统计文件信息

**含义：** 统计文件的字节数、字数、行数

**语法：** `wc [选项] (文件)`

**常用选项：**

| 选项 | 描述     |
| ---- | -------- |
| -l   | 统计行数 |

**示例：**

```bash
# 基础格式（行数 单词数 字节数）
[root@linux141 ~]# wc /etc/sysconfig/network-scripts/ifcfg-eth1
 18  18    324 /etc/sysconfig/network-scripts/ifcfg-eth1

# 统计行数
[root@linux141 ~]# wc -l /etc/sysconfig/network-scripts/ifcfg-eth1
18 /etc/sysconfig/network-scripts/ifcfg-eth1

[root@linux141 ~]# ps -ef | wc -l
119
```

### 8. sort – 排序

**含义：** 排序

**语法：** `sort [选项] (排序内容)`

**常用选项：**

| 选项 | 描述               |
| ---- | ------------------ |
| -n   | 按照数字排序       |
| -r   | 逆序排序           |
| -k   | 根据某一列进行排序 |
| -t   | 指定分隔符号       |

**示例：**

```bash
# 数字排序（不加-n效果）
[root@linux141 ~]# seq 20 | sort
1
10
11
...
# 使用-n选项
[root@linux141 ~]# seq 20 | sort -n

# 逆序排序
[root@linux141 ~]# seq 20 | sort -rn

# 根据第三列排序
[root@linux141 ~]# cat sort-num.txt
1 linux 1000000 20000
2 liuux 20000 60000
3 wang 300000 5000
4 lnux 90000 5000
5 unix 130000 0
10 python 300000 0
[root@linux141 ~]# sort -rn -k3 sort-num.txt

# 根据第4列的第1-2个字符排序
[root@linux141 ~]# sort -t '.' -rn -k4.1,4.2 -k3 ip.txt
```

### 9. uniq – 去重

**含义：** 显示或忽略重复的行（通常与sort结合使用）

**语法：** `uniq [选项] [文件]`

**常用选项：**

| 选项 | 描述         |
| ---- | ------------ |
| -c   | 显示重复次数 |

**示例：**

```bash
# 基础格式（只去重相邻重复行）
[root@linux141 ~]# cat uniq.txt
a
a
a
b
b
c
c
b
[root@linux141 ~]# uniq uniq.txt
a
b
c
b

# 与sort结合
[root@linux141 ~]# sort uniq.txt | uniq
a
b
c

# 显示重复次数
[root@linux141 ~]# sort uniq.txt | uniq -c
      5 a
      5 b
      3 c

# 统计IP访问次数前十
[root@linux141 ~]# sort access-ip.log | uniq -c | sort -rnk1 | head
  12049 58.220.223.62
  10856 112.64.171.98
   1982 114.83.184.139
```

### 11. vim/vi – 文本编辑器

**含义：** 文本编辑器

**语法：** `vi (文件)`

**常用操作：**

| 操作                   | 命令                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 进入编辑模式           | `i`（插入）、`a`（追加）、`o`（下行插入）、`O`（上行插入）、`A`（行尾插入） |
| 退出编辑模式           | `Esc`                                                        |
| 保存退出               | `:wq`                                                        |
| 强制保存退出           | `:wq!`                                                       |
| 不保存退出             | `:q!`                                                        |
| 显示行号               | `:set nu`                                                    |
| 取消行号               | `:set nonu`                                                  |
| 向下查找               | `/关键词`                                                    |
| 继续向下查找           | `n`                                                          |
| 继续向上查找           | `N`                                                          |
| 取消高亮               | `:noh`                                                       |
| 撤销                   | `u`                                                          |
| 恢复                   | `Ctrl + r`                                                   |
| 复制光标所在行         | `yy`                                                         |
| 粘贴                   | `p`                                                          |
| 删除当前行             | `dd`                                                         |
| 删除到文件末尾         | `dG`                                                         |
| 移动到行首             | `0` 或 `^`                                                   |
| 移动到行尾             | `$`                                                          |
| 移动到文件首行         | `gg` 或 `:1`                                                 |
| 移动到文件末行         | `G` 或 `:$`                                                  |
| 替换当前行第一个匹配   | `:s/old/new/`                                                |
| 替换当前行所有         | `:s/old/new/g`                                               |
| 替换整个文件           | `:%s/old/new/g`                                              |
| 可视块模式（批量编辑） | `Ctrl+v`，选择区域，`Shift+i` 输入，`Esc` 完成               |

```bash
# 启动top

# 只显示特定进程
top -p 1907

# 批处理模式输出一次
top -bn1 | head -20

# 查看进程的线程
top -Hp 26254
```

### 3. htop – 增强版 top

**含义：** 需要额外安装，更友好的交互式进程查看器

**安装：** `yum install -y htop`

### 4. pstree – 显示进程树

**含义：** 以树状图的方式展现进程之间的派生关系

**常用选项：** `-p` 显示进程号和进程id

**示例：**

```bash
[root@localhost ~]# pstree
systemd─┬─NetworkManager─┬─{NetworkManager}
        │                └─{NetworkManager}
        ├─sshd─┬─sshd─┬─bash───pstree
        │      │      └─bash
        │      └─sshd───sftp-server

[root@localhost ~]# pstree -p | grep sshd
```

### 5. pgrep – 按条件查找进程PID

**含义：** 根据用户给出的信息在当前运行进程中查找并列出符合条件的进程ID（PID）

**常用选项：**

| 选项 | 描述                 |
| ---- | -------------------- |
| -u   | 指定进程的有效用户ID |
| -l   | 显示进程名称         |
| -P   | 指定父进程号         |

**示例：**

```bash
# 列出linux用户的所有进程
[root@localhost ~]# pgrep -l -u linux
32206 sshd
32207 bash
```

### 6. kill – 通过PID终止进程

**含义：** 通过pid和信号杀掉进程

**语法：** `kill [信号] [进程id]`

**常用信号：**

| 信号 | 描述                                |
| ---- | ----------------------------------- |
| 1    | 进程重新读取配置文件，优雅重启服务  |
| 2    | 中断信号，类似 Ctrl+C               |
| 3    | 退出进程                            |
| 9    | 强制结束进程，慎用                  |
| 15   | 停止，kill 默认使用的信号           |
| 18   | 恢复被暂停的进程                    |
| 19   | 暂停进程                            |
| 20   | 类似于 Ctrl+Z，把进程放到后台并暂停 |

**示例：**

```bash
# 默认发送15信号
kill 12345

# 强制杀死
kill -9 12345

# 优雅重启（重新加载配置）
kill -1 12345
```

### 7. killall – 按进程名终止进程

**含义：** 通过进程名称(完整名称)杀掉进程

**示例：**

```bash
[root@localhost ~]# killall sh
```

### 8. pkill – 按进程名终止进程（模糊匹配）

**语法：** `pkill 进程名`

**示例：**


### 9. runlevel – 查看当前运行级别

### 10. init – 切换运行级别

### 6. fdisk – 磁盘分区工具

**含义：** 查看磁盘使用情况和磁盘分区

| 命令 | 描述           |

## 九、网络管理命令

### 1. telnet – 远程登录/端口测试

**含义：** 测试远程主机端口是否开放

**示例：**

```bash
[root@linux142 ~]# telnet 10.0.0.1 22
Trying 10.0.0.1...
Connected to 10.0.0.1.
```

### 2. nc (netcat) – 网络工具

**含义：** 网络连接、端口扫描、数据传输

**示例：**

```bash
# 监听端口
nc -l 1234
# 连接端口
nc 10.0.0.1 1234
```

### 3. netstat – 网络状态查看

**含义：** 显示网络连接、路由表、接口统计等信息

**常用选项：**

| 选项  | 描述      |
| --- | ------- |
| -t  | TCP 端口  |
| -u  | UDP 端口  |
| -l  | 监听状态    |
| -n  | 不解析域名   |
| -p  | 显示进程PID |
| -a  | 所有连接    |
| -r  | 路由表     |

**示例：**

```bash
# 查看所有监听端口
[root@linux142 ~]# netstat -tunlp
# 查看路由表
[root@linux142 ~]# netstat -rn
```

### 4. ping – 测试网络连通性

**含义：** 发送ICMP包测试网络连接

**常用选项：** `-c` 指定次数，`-i` 间隔秒数

**示例：**

```bash
[root@linux142 ~]# ping -c 4 10.0.0.1
```

### 5. tcpdump – 网络抓包工具

**含义：** Linux抓包命令

**语法：** `tcpdump [选项]`

**常用选项：**

| 选项  | 描述       |
| --- | -------- |
| -i  | 指定网卡     |
| -n  | 不解析主机名   |
| -A  | 以ASCII显示 |
| -w  | 保存到文件    |
| -r  | 读取文件     |

**示例：**

```bash
# 监视指定网络接口的数据包
tcpdump -i eth1

# 截获所有10.0.0.1的主机收到的和发出的所有的数据包
tcpdump host 10.0.0.1

# 抓取80端口的HTTP报文，以文本形式展示
tcpdump -i any port 80 -A

# 保存到文件
tcpdump -i eth0 -w capture.pcap
```

### 6. traceroute – 路由追踪

**含义：** 显示数据包到目标主机的路由路径

**示例：**

```bash
[root@linux142 ~]# traceroute www.baidu.com
```
